# Sliding Window Visualizer 🚀
An interactive web application built with Streamlit to visualize the "Longest Substring Without Repeating Characters" algorithm.<br>

# The Challenge:
This project visualizes a classic LeetCode Medium problem. The goal is to find the length of the longest substring without repeating characters using an optimized Sliding Window technique.<br>
Tech Stack Language: Python <br>
Library: Streamlit (UI/UX)<br>
Logic: Two-pointer approach / Sliding Window ($O(n)$ complexity)<br>


# 🌟 Features
Interactive Input: Test any string in real-time.<br>
Visual State Tracking: See how the "window" expands and contracts.<br>
Performance: Uses a Hash Map (Dictionary) for $O(1)$ lookups of character indices.<br>

# How to Run
Install requirements:
```bash
pip install streamlit
```
Run the app: streamlit run app.py<br>
