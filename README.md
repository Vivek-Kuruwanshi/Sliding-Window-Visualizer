# Sliding Window Visualizer 🚀
An interactive web application built with Streamlit to visualize the "Longest Substring Without Repeating Characters" algorithm.

# The Challenge:
This project visualizes a classic LeetCode Medium problem. The goal is to find the length of the longest substring without repeating characters using an optimized Sliding Window technique.
Tech Stack Language: Python 
Library: Streamlit (UI/UX)
Logic: Two-pointer approach / Sliding Window ($O(n)$ complexity)


🌟 FeaturesInteractive Input: Test any string in real-time.Visual State Tracking: See how the "window" expands and contracts.Performance: Uses a Hash Map (Dictionary) for $O(1)$ lookups of character indices.🚀

# How to Run
Install requirements: pip install streamlit
Run the app: streamlit run app.py
